---

## Featured work
- **[Picture Axe](https://www.curseforge.com/minecraft/mc-mods/picaxe)** — Put images from the web onto beds, banners, shields, a six-sided image block and a resizable frame. 20K+ downloads on CurseForge. Inspired by the Images mod.
- **[Ryujinx / Ryubing](https://git.ryujinx.app/projects/Ryubing)** — Contributed features including **Amiibo .bin file support** and the **Cabinet menu**.
- **[Minecraft: Wii U Edition Reconstructed](https://github.com/Jacobwasbeast/mcwiiu-reconstructed)** — Reconstructed C++ source for Minecraft: Wii U Edition. Builds and runs in Cemu, boots to menus, and creates and loads worlds.
